## 🚀 Getting Started

Clone the repo:

```bash
git clone https://github.com/DSATM1/Leetcode.git
cd Leetcode
```

Run any solution directly with Python 3:

```bash
python3 1-two-sum/two-sum.py
```

> Most solutions define the function/class described in the problem statement (e.g. LeetCode's `Solution` class). Some files may need a small `if __name__ == "__main__":` block added if you want to run them with custom input locally.

## 🗂️ How Problems Are Organized

Folders are named using the pattern:

```
<leetcode-problem-number>-<kebab-case-problem-title>
```

For example, `1522-stone-game-iii` corresponds to [LeetCode problem 1522: Stone Game III](https://leetcode.com/problems/stone-game-iii).
